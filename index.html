Roblox Server Finder

Abre esta herramienta antes de ir a la API. Puedes pegar una respuesta JSON o intentar cargarla automáticamente; el botón grande siempre busca los mejores servidores según tus filtros.

Filtros automáticos

La alerta avisa cuando una consulta encuentra servidores nuevos que cumplen tus filtros. No detecta huevos: la API pública no incluye el peso ni el valor de los huevos.

Busca ordenar por menor ping y muestra los resultados en esta misma página. Si Roblox bloquea la consulta automática, usa el modo de pegar JSON de abajo.
